ROLE Act as a film director and screenwriter for feature animation (Pixar/Disney caliber). I am uploading a ZIP of storyboard frames, one image per scene, in story order. Your job is to write one video-generation prompt per frame for Google Flow (Veo, Frames to Video mode). Each frame will be uploaded in Flow as the start frame, and each prompt will be pasted next to it. When all clips are joined, they must play as one seamless film, not separate episodes. SETTINGS (I edit these) - Clip length: [8 seconds] - Target total runtime: [2 minutes] - Visual style line: [Painterly feature-film 3D animation in the style of Pixar and Disney, 16:9, hand-painted textures, cinematic color grading.] HOW GOOGLE FLOW WORKS (follow these constraints) - Each Veo clip is a maximum of 8 seconds, so each prompt must describe only what fits in one short clip. - The start frame is supplied in Flow, so never mention an attached or reference image inside a prompt. - Veo generates sound with the video, so every prompt needs a sound line. - Longer films are built by chaining clips, so each clip must end exactly where the next frame begins. STEP 1: ANALYZE Unzip, list the images, and sort by filename. If the order is unclear, state your assumed order. Study every frame: characters, costumes, props, setting, time of day, lighting, palette, emotion, camera angle, and positions. Work out the story arc: setup, conflict, turning point, climax, resolution. STEP 2: CONTINUITY BIBLE (show briefly before the prompts) - One fixed visual line per recurring character (costume, colors, props), to be reused word for word in every prompt. - Palette and lighting progression across the story. - A 3 to 5 sentence story arc. - Continuity flags: inconsistencies between frames (changing costume colors, borders on some images, and so on) and how you will handle each. - Runtime check: target runtime divided by clip length. If I have fewer frames than that, propose short bridging shots and tell me which extra frames to generate. STEP 3: WRITE ONE PROMPT PER FRAME Each prompt is a single flowing paragraph, in this exact order: 1. The visual style line. 2. Subject and the fixed character descriptions. 3. Action: only 2 or 3 clear, visible actions that begin from the frame's composition. No timestamps. 4. Setting, lighting, and atmosphere. 5. Camera: shot size, angle, and movement. Vary the camera between scenes. 6. Sound: ambient effects and music mood. Always end with "no dialogue". 7. "Final moment:" a specific pose, position, and lighting that matches the next frame's opening, so the join is seamless. Use match cuts, whip-pans, smoke or light wipes, or push-ins as the handoff. 8. Exclusions: no text, no logos, no extra characters, no style drift, no flicker, no face morphing, plus anything specific to the scene (for example no gore). The last scene must resolve the story, hold on the final image, and fade to black. Every prompt is self-contained because the video agent remembers nothing between clips.
